Code lesen wie ein Profi

Ihr habt vier Projekte programmiert: Abstand messen, Thermometer, Schranke schließen und die automatische Schranke. Auf dieser Seite lernt ihr, jeden dieser Codes zu lesen, ihn in eigenen Worten zu erklären – und ihn dann selbst zu verändern.

Das könnt ihr am Ende

  • Ich kann erklären, wozu lib/controller.py und main.py da sind.
  • Ich kann an einem Bauteilnamen ablesen, welches Bauteil an welchem Anschluss steckt.
  • Ich unterscheide Sensor-Fragen (liefern einen Wert) von Aktor-Befehlen (tun etwas).
  • Ich erkenne Schleifen, Entscheidungen und Funktionen an der Einrückung und kann sie als Satz „vorlesen“.
  • Ich kann vorhersagen, was ein Programm tut, es gezielt anpassen und Fehler finden.

Die 4-Schritte-Lesemethode

So geht ihr an jeden Code heran – egal wie lang er ist. Diese vier Schritte übt ihr auf jeder Seite.

1

🔎 Überblick

Kopfkommentar und import-Zeilen lesen: Was soll das Programm tun? Welche Bauteile braucht es?

2

🧩 Bauteile

Namen zerlegen (TXT_M_I1_…). Wo wird ein Sensor gefragt, wo ein Aktor befohlen?

3

🧱 Struktur

Der Einrückung folgen: Welche Zeilen gehören zu welcher Schleife, Entscheidung oder Funktion?

4

▶️ Durchspielen

Zeile für Zeile mit echten Werten: Was steht jetzt in der Variablen? Was zeigt das Display?

Baustein 1

Das Gerüst: zwei Dateien, ein Namensschema

Jedes ROBO-Pro-Coding-Projekt besteht aus mindestens zwei Python-Dateien. Wer weiß, was wo steht, findet sich in jedem Code zurecht.

📋 lib/controller.py – die Stückliste

Hier steht, welche Bauteile an welchem Anschluss stecken. ROBO Pro Coding erzeugt diese Datei automatisch, sobald ihr die Bauteile im Controller-Fenster eintragt. Nicht abtippen, nicht verändern!

📝 main.py – die Bauanleitung

Hier steht, was passieren soll: messen, warten, Motor starten … Das ist die Datei, die ihr programmiert. Die erste Zeile holt alle Bauteile aus der Stückliste:

from lib.controller import *   # alle Bauteile holen

So sieht die Stückliste von Projekt 3 aus


  

    
① Bibliothek laden: import fischertechnik.factories as txt_factory – die „Fabriken“, die für jedes Bauteil ein Python-Objekt bauen.

    
② Vorbereiten: txt_factory.init…() – nur die Fabriken, die das Projekt braucht (Eingänge, Motoren, Zähler).

    
③ Bauteile erzeugen: create_…(TXT_M, 1) – Bauteiltyp + Controller + Anschlussnummer. Das Ergebnis bekommt einen Namen.

Baustein 2
Der Wortschatz: Befehle der Bauteile

  
Jedes Bauteil ist ein Objekt. Mit einem Punkt gebt ihr ihm einen Befehl (eine Methode). Lest den Punkt wie „…, bitte …!“


  

    
TXT_M_M1_encodermotorWER?
.
    
set_speedWAS?

    
(200, Motor.CW)WIE? (Werte)

  

  
→ Lies so: „Encodermotor an M1, stelle bitte Geschwindigkeit 200 im Uhrzeigersinn ein.“


  

    

      
❓ Sensoren fragen – sie liefern einen Wert

      

        
Befehlliefert

        
.get_distance()Abstand in cm als ganze Zahl (int), z. B. 23

        
.get_temperature()Temperatur in °C als Kommazahl (float), z. B. 22.4378

        
.is_closed()True = Taster gedrückt, False = nicht gedrückt

      

      
Erkennungszeichen: Die Frage steht rechts vom = (Wert wird gespeichert) oder hinter if / while (Wert wird geprüft).

      
abstand = TXT_M_I2_ultrasonic_distance_meter.get_distance()
while not TXT_M_I1_mini_switch.is_closed():

    

    

      
❗ Aktoren befehlen – sie tun etwas

      

        
Befehlbewirkt

        
.set_speed(200, Motor.CW)stellt Tempo (0 … 512) und Richtung ein – fährt noch nicht!

        
.start()Motor fährt los

        
.stop()Motor hält an

      

      
Richtung bei der Schranke: Motor.CW (im Uhrzeigersinn) = zu, Motor.CCW (gegen den Uhrzeigersinn) = auf.
Erkennungszeichen: Der Befehl steht allein in einer Zeile.

      
TXT_M_M1_encodermotor.set_speed(200, Motor.CW)
TXT_M_M1_encodermotor.start()

    

    

      
🖥️ Ausgeben

      

        
display.set_attr("txt_label.text", text)schreibt text in das Label txt_label auf dem TXT-Display. Braucht from lib.display import *

        
print(...)schreibt in die Konsole – praktisch zur Fehlersuche

      

    

    

      
🧰 Python-Werkzeuge

      

        
str(23)Zahl → Text: "23"

        
round(22.4378, 1)runden auf 1 Nachkommastelle: 22.4

        
time.sleep(0.5)0,5 Sekunden warten. Braucht import time

        
range(10)die Zahlen 0, 1, …, 9 (für for-Schleifen)

      

    

  

  
Merke: Text und Zahl kann man nicht mit + verbinden. "Abstand: " + 23 ergibt einen TypeError. Richtig: "Abstand: " + str(23) → "Abstand: 23".

Die Grammatik: 7 Muster, die immer wiederkommen

  
Python zeigt die Struktur durch Einrückung (4 Leerzeichen). Alles, was unter einer Zeile mit Doppelpunkt eingerückt ist, gehört zu ihr – wie Unterpunkte in einer Liste.


  

    
for i in range(10):                 # Kopfzeile mit Doppelpunkt
    temp = TXT_M_I1_ntc_resistor.get_temperature()   # gehört zur Schleife
    time.sleep(1)                   # gehört zur Schleife
display.set_attr("txt_label.text", "fertig")         # NICHT eingerückt: erst danach

    
Lesetrick: Blöcke umrahmen
Fahrt mit dem Finger an der Einrückung nach unten. Wo die Einrückung endet, endet der Block. Im Code-Leser (Baustein 4) könnt ihr die Blöcke mit dem Schalter „Struktur“ farbig markieren lassen.
