1 Warum Text statt Blöcke?

In Blockly hast du Programme aus Bausteinen zusammengesteckt. Jeder Baustein ist in Wahrheit eine Zeile Python-Code: ROBO Pro Coding übersetzt deine Blöcke im Hintergrund in Python. Profis schreiben den Text direkt – das ist schneller, lässt sich kopieren, vergleichen und kommentieren. Python ist eine Hochsprache: Sie liest sich fast wie Englisch und wird erst beim Ausführen in Maschinencode (Nullen und Einsen) übersetzt.

2 So ist ein TXT-Programm aufgebaut

Wie beim Bauen nach Anleitung öffnest du zuerst die Kisten (Importe), dann gibst du den Bauteilen Namen (Konfiguration) und erst danach kommt das eigentliche Hauptprogramm.

import time                      # 1. Werkzeugkasten "Zeit" öffnen
from lib.controller import *     # 2. Konfiguration: alle Sensoren/Motoren mit ihren Namen
from lib.display import *        #    Display des TXT

# 3. Hauptprogramm
while True:
    widerstand = TXT_M_I1_ntc_resistor.get_resistance()      # Sensor an I1 lesen
    display.set_attr("txt_label.text", str(widerstand) + " Ohm")
    time.sleep(1)                                            # 1 Sekunde warten
🤖 Auf dem echten TXT 4.0
Die Namen wie TXT_M_I1_ntc_resistor entstehen automatisch, wenn du in ROBO Pro Coding unter Konfiguration ein Bauteil an einen Anschluss steckst: TXT_M = Haupt-Controller, I1 = Eingang 1, ntc_resistor = Bauteiltyp. Sie stehen in der Datei lib/controller.py. Tipp: Baue ein Programm in Blockly und schalte dann auf die Python-Ansicht um – dort siehst du den übersetzten Code. Der Name des Display-Labels (hier txt_label) hängt davon ab, wie du das Label im Display-Editor genannt hast.

3 Kommentare mit #

Alles hinter einer Raute # ignoriert der Computer. Kommentare helfen Menschen: zur Erklärung (Motor auf halbe Kraft), zur Gliederung (--- Hauptschleife ---) und zum Auskommentieren einer Zeile beim Testen.

4 Variablen – beschriftete Kisten

Eine Variable ist eine Kiste mit Namen, in die du einen Wert legst: abstand = 25. Namen schreibt man klein, ohne Leerzeichen und Umlaute (temp_max, nicht Temp Max). = bedeutet „lege hinein“, nicht „ist gleich“.

Aufgabe 1.1Widerstand messen (A1, Programmieraufgabe 1)Basis
Am Eingang I1 steckt der NTC-Widerstand. Lies 5-mal im Abstand von 1 s den Widerstand und zeige ihn jeweils als … Ohm auf dem Display an. Gib ihn zusätzlich mit print aus.

Am Eingang I2 steckt der Ultraschallsensor. Zeige 10 Sekunden lang jede halbe Sekunde den Abstand in cm an (Display und Konsole). Nutze eine while-Schleife mit einer Zählvariablen.
Aufgabe 1.3Pseudocode → Python (Material 3.1)Basis
Übersetze den Pseudocode in Python. Die Werte der Variablen sollen am Ende mit print erscheinen: Setze Geschwindigkeit auf 200. Setze Fahrzeit auf 5. Berechne Gesamtzeit = 2 · Fahrzeit + 2 (Pause). Gib „Gesamtzeit: 12 s“ aus.
