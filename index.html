🤖 Python & RobotikPython wird beim Öffnen einer Lektion geladen
Vertiefungskurs Robotik · Rob10/11Lernbereich 3fischertechnik TXT 4.0

Einen Roboter mit einer Hochsprache programmieren

Python lernen mit dem fischertechnik TXT 4.0: 14 Lektionen, jede passend zu einem Kapitel im Skript. Die Python-Aufgaben laufen direkt im Browser – ein Simulator zeigt LEDs, Display, Motoren, die Schranke, den Buggy und einen 3D-Portalroboter. Danach überträgst du den Code auf den echten TXT.

So arbeitest du in jeder Lektion
  1. Lesen: den angegebenen Abschnitt im Skript
  2. Verstehen: Fragen mit dem Skript beantworten (mind. 70 %)
  3. Vertiefen: Simulationen (Vermutung → ausprobieren → erklären) und Python-Aufgaben
  4. Abschluss: Rückmeldung lesen und Lektion abschließen
Kompetenzen LB 3
  • aus Schaltungen den Code ableiten
  • eine Hochsprache anwenden
  • (3D-)Koordinaten implementieren
  • KI-Anwendungen integrieren
