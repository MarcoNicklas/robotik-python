Einen Roboter mit einer Hochsprache programmieren

Python lernen mit dem fischertechnik TXT 4.0: 14 Lektionen mit Erklärungen, Beispielen und Aufgaben. Jede Aufgabe läuft direkt im Browser – ein Simulator zeigt LEDs, Display, Motoren, die Schranke, den Buggy und einen 3D-Portalroboter. Danach überträgst du den Code auf den echten TXT.

So arbeitest du
  • Lektion öffnen (Internet nötig, Python lädt einmalig ca. 10 MB)
  • Code ändern → ▶ Ausführen → Simulation ansehen
  • ✓ Prüfen sagt dir, ob die Aufgabe gelöst ist
  • Dein Code wird im Browser gespeichert
Kompetenzen LB 3
  • aus Schaltungen den Code ableiten
  • eine Hochsprache anwenden
  • (3D-)Koordinaten implementieren
  • KI-Anwendungen integrieren
