1 Funktionen: Befehle selbst erfinden

Eine Funktion fasst mehrere Befehle unter einem Namen zusammen – wie ein Unterprogramm in Blockly (definiere …). Parameter sind Eingabewerte, mit return gibt die Funktion ein Ergebnis zurück.

def blinken(anzahl, dauer):            # Definition mit 2 Parametern
    for i in range(anzahl):
        TXT_M_O1_led.set_brightness(512)
        time.sleep(dauer)
        TXT_M_O1_led.set_brightness(0)
        time.sleep(dauer)

def impulse_fuer_winkel(winkel):       # Funktion mit Rückgabewert
    return round(winkel / 90 * 64)

blinken(3, 0.5)                        # Aufruf
print(impulse_fuer_winkel(45))         # -> 32
Aufgabe 5.1Blinklicht (A3, Experimentieraufgabe 1)Basis
Nach dem Drücken des Tasters I1 soll die rote LED an O1 5-mal je 0,5 s an und 0,5 s aus gehen. Schreibe dafür die Funktion blinken(anzahl).
Aufgabe 5.2Bedarfsampel (A3, Programmieraufgabe 1)Basis
Rote LED O3, grüne LED O4, Bedarfstaster I1. Ruhezustand: rot. Taster gedrückt → nach 3 s grün → nach 5 s wieder rot. Das Programm läuft 30 s. Schreibe die Funktionen rot() und gruen().
Aufgabe 5.3Funktion mit RückgabewertBasis
Schreibe impulse_fuer_winkel(winkel): 90° entsprechen 64 Impulsen. Ergebnis als ganze Zahl (round).

2 Zwei Dinge gleichzeitig: nebenläufige Prozesse

Die Schranke soll öffnen und gleichzeitig das Warnlicht blinken. Mit time.sleep() blockiert das Programm aber. Lösung 1 auf dem TXT: ein Thread (nebenläufiger Prozess) – das Blinken läuft in einem eigenen Programmstrang:

import threading

blinken_aktiv = False

def blinklicht():                      # läuft parallel zum Hauptprogramm
    while True:
        if blinken_aktiv:
            TXT_M_O1_led.set_brightness(512); time.sleep(0.5)
            TXT_M_O1_led.set_brightness(0);   time.sleep(0.5)
        else:
            time.sleep(0.05)

threading.Thread(target=blinklicht, daemon=True).start()
blinken_aktiv = True      # Hauptprogramm "triggert" das Blinken
oeffnen()

Lösung 2 (läuft überall, auch im Simulator): die Zeitscheiben-Methode. Die Schleife wartet nie lange, sondern schaut bei jedem Durchlauf auf die Uhr: „Sind seit dem letzten Umschalten 0,5 s vergangen?“

Aufgabe 5.4Blinken während die Schranke öffnet (A3, Experimentieraufgabe 2)Profi
Öffne die Schranke langsam (Geschwindigkeit 100, 64 Impulse). Während der Motor läuft, soll die LED O1 alle 0,5 s umschalten. Danach LED aus.
Merke
Funktionen machen Programme kürzer, lesbarer und wiederverwendbar. Für Gleichzeitigkeit nutzt man auf dem TXT Threads – oder eine Schleife ohne lange Wartezeiten (Zeitscheiben).
